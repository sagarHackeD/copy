Input : Connected weighted graph G(V, E)
Output: Minimum Spanning Tree (MST)

1. Sort all edges in non-decreasing order of weight.
2. MST <- empty set
3. Create a separate set for each vertex.

4. For each edge (u, v) in sorted order do
      if Find(u) != Find(v) then
           Add edge (u, v) to MST
           Union(u, v)
      end if
   end for

5. Return MST
