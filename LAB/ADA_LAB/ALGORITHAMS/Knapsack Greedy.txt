Fractional
Input : weights, profits, capacity W
1. Compute profit/weight ratio for each item.
2. Sort items in descending order of ratio.
3. profit <- 0
4. For each item do
      if item weight <= W then
           Take complete item
           profit <- profit + item profit
           W <- W - item weight
      else
           Take fraction of item
           profit <- profit +
                    ratio X W
           Break
      end if
   End For
5. Return profit

Discrete
1. Compute profit/weight ratio.
2. Sort items in descending ratio order.
3. For each item do
      if weight <= remaining capacity then
           Select item
           Reduce capacity
      end if
   End For
4. Return selected items
