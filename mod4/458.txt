458. Solve (a_n - 3a_{n-1} = 5▪ 3^n, a_0=2)
Homogeneous solution: (a_n^{(h)} = C▪ 3^n).  
Since the RHS is also a multiple of (3^n), try a particular solution of the form (a_n^{(p)} = A n 3^n).
Substitute:
[A n 3^n - 3A(n-1)3^{n-1} = A n 3^n - A(n-1)3^n = A▪ 3^n.]
Set equal to (5▪ 3^n), so (A=5).  
Thus:
[a_n = C 3^n + 5n 3^n = (C+5n)3^n.]
Using (a_0 = 2):
[C = 2    →    a_n = (2+5n)3^n.]
[\boxed{a_n = (2+5n)3^n}]
