36. Inference Rules in Functional Dependency (Armstrong's Axioms) with Proof
Armstrong's axioms are a set of rules that are sound (any FD derived using them is logically implied by the given FDs) and complete (all logically implied FDs can be derived). The three primary axioms:
1. Reflexivity: If Y E X, then X -> Y.  
   *Proof:* Trivial; if two tuples agree on all attributes of X, they agree on any subset Y.
2. Augmentation: If X -> Y, then XZ -> YZ for any set Z.  
   *Proof:* Let two tuples t1 and t2 agree on XZ. They agree on X and on Z. Since X -> Y, they also agree on Y. Thus they agree on YZ.
3. Transitivity: If X -> Y and Y -> Z, then X -> Z.  
   *Proof:* Let t1, t2 agree on X. By X -> Y, they agree on Y. By Y -> Z, they agree on Z. Hence X -> Z.
Secondary (derivable) rules often used:
- Union: If X -> Y and X -> Z, then X -> YZ.  
  *Proof:* From X -> Y, augment by X: X -> XY. From X -> Z, augment by Y (and X): XY -> YZ. By transitivity, X -> YZ.
- Decomposition: If X -> YZ, then X -> Y and X -> Z.  
  *Proof:* YZ E YZ, so by reflexivity YZ -> Y. By transitivity from X -> YZ and YZ -> Y, we get X -> Y. Similarly X -> Z.
- Pseudotransitivity: If X -> Y and WY -> Z, then XW -> Z.  
  *Proof:* From X -> Y, augment by W: XW -> WY. Combine with WY -> Z by transitivity, XW -> Z.
These rules allow us to compute the closure of a set of attributes or FDs and to find minimal covers.
