126. Proofs for “If (n) is odd then (n+9) is even”
(i) Direct proof:  
Assume (n) is odd. Then (n=2k+1) for some integer (k).  
Then
[n+9 = 2k+1+9 = 2k+10 = 2(k+5),]
which is even.
(ii) Indirect proof (contrapositive):  
Prove: If (n+9) is odd, then (n) is even.  
Assume (n+9) is odd. Then (n+9=2k+1). So
[n = 2k+1-9 = 2k-8 = 2(k-4),]
which is even. Hence the contrapositive holds, so the original statement is true.
(iii) Proof by contradiction:  
Assume the statement is false: there exists an odd integer (n) such that (n+9) is not even (i.e. odd).  
Let (n=2k+1). Then
[n+9=2k+10=2(k+5),]
which is even, contradicting the assumption that (n+9) is odd. Therefore the statement is true.
