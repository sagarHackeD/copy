17. Current Program Status Register (CPSR) - Detailed
The CPSR is a 32-bit register that holds the processor status and control bits.
Bit Layout:
```
|-flags-||-status-||-extention-||-controll-|
31  30  29  28   27   26...25   24   23...20   19...16   15...10   9    8    7    6    5    4........0
+----+----+----+----+----+-------+----+---------+---------+---------+----+----+----+----+-------------+
| N  | Z  | C  | V  | Q  |       | J  |         |   GE    |         | E  | A  | I  | F  | T  |    M[4:0]  |
+----+----+----+----+----+-------+----+---------+---------+---------+----+----+----+----+-------------+
condition flags                                                            interupt mask    processor mode
```
| Bits | Name | Description |
| 31 | N (Negative) | Set if the result of an operation is negative (bit 31 = 1). |
| 30 | Z (Zero) | Set if the result of an operation is zero. |
| 29 | C (Carry) | Set if an addition generates a carry, or subtraction generates a borrow. |
| 28 | V (Overflow) | Set if arithmetic overflow occurs. |
| 27 | Q (Sticky Overflow) | Set by DSP instructions; indicates saturation occurred. |
| 24 | J (Jazelle) | Indicates whether the processor is in Java (Jazelle) state. |
| 19-16 | GE (Greater/Equal) | Used by SIMD instructions to indicate byte/word comparisons. |
| 9 | E (Endianness) | 0 = Little-endian, 1 = Big-endian. |
| 8 | A (Abort Disable) | 1 = Disables imprecise data aborts. |
| 7 | I (IRQ Disable) | 1 = Disables normal interrupts. |
| 6 | F (FIQ Disable) | 1 = Disables fast interrupts. |
| 5 | T (Thumb State) | 1 = Processor is executing Thumb (16-bit) instructions; 0 = ARM (32-bit). |
| 4-0 | M[4:0] (Mode bits) | Defines the current processor mode (e.g., 0b10000 = User, 0b10011 = SVC). |
