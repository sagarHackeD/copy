18) Every block of 5 consecutive symbols has at least two \(a\)’s

State marking:

- Start state: `→ ε`
- Accept states: `* u` for every \(u\in\{a,b\}^{\le 4}\)
- Non-accepting dead state: `X`

Compact transition table:


State u with |u| < 4:
    δ(u,a) = ua
    δ(u,b) = ub

State u with |u| = 4:
    if #a(u) + [c = a] >= 2 then δ(u,c) = last4(uc)
    else δ(u,c) = X

State X:
    δ(X,a) = X
    δ(X,b) = X


So the start/accept information is:


→ ε        start
* u        accept for all u ∈ {a,b}≤4
  X        non-accepting
