10) Definitions with examples

Alphabet - A finite, non-empty set of symbols is called an alphabet, denoted by (Sigma).
Example: (Sigma={0,1}).

Reversal of a string - The reversal of a string (w), denoted by (w^R), is obtained by writing its symbols in reverse order.
Example: If (w=1011), then (w^R=1101).

Power of an alphabet - The (n)-th power of an alphabet is the set of all strings of length (n) formed from that alphabet.
Example: If (Sigma={a,b}),
[ Sigma^2={aa,ab,ba,bb} ]
Also, (Sigma^0={epsilon}), where (epsilon) is the empty string.

Language - A language is any set of strings over an alphabet.
Example: (L={a,ab,abb}).

String - A string is a finite sequence of symbols from an alphabet.
Example: abba is a string over (Sigma={a,b}).

Concatenation - Concatenation means joining two strings together.
Example: If (x=ab) and (y=ba), then (xy=abba).
