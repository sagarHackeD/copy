Input : Connected weighted graph G(V, E)
Output: Minimum Spanning Tree

1. Select starting vertex.
2. Mark start vertex as visited.
3. MST <- empty set

4. Repeat until (V-1) edges are selected
      Find minimum weight edge (u, v)
      such that u is visited and v is unvisited.

      Add edge (u, v) to MST
      Mark v as visited
   end repeat

5. Return MST
