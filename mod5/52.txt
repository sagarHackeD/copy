52. Basic Architecture of Cache Memory
A cache is not just a single block of RAM; it is highly structured to allow fast searches. The architecture consists of a Cache Controller and the Cache Memory Array.
Diagram of Cache Architecture:
```
+------------------------------------------+
|             CPU Core                       |
|  (Generates 32-bit Address)               |
+------------------+-----------------------+
               | (Address Bus)
               v
+------------------------------------------------------------+
|                    CACHE CONTROLLER                        |
|  +-------------+  +-------------+  +------------------+   |
|  | Address     |  | Comparator  |  | Control Logic    |   |
|  | Decoder     |  | (Tag Check) |  | (Hit/Miss, RD/WR)|   |
|  +-------------+  +------+------+  +------------------+   |
+--------------------------|----------------------------------+
                       | (Hit/Miss signal)
                       v
+------------------------------------------------------------+
|                CACHE MEMORY ARRAY (SRAM)                   |
|  +----------+----------+----------+----------+----------+ |
|  |  Valid   |   Tag    |   Data   |  Dirty   |   LRU    | |
|  |  Bit     |  (Addr)  |  (Block) |  Bit    |   Bits   | |
|  +----------+----------+----------+----------+----------+ |
|  |  Line 0  |  Tag 0   |  Bytes 0-31|  D0    |   ...    | |
|  |  Line 1  |  Tag 1   |  Bytes 0-31|  D1    |   ...    | |
|  |  Line 2  |  Tag 2   |  Bytes 0-31|  D2    |   ...    | |
|  |  ...     |  ...     |  ...       |  ...   |   ...    | |
|  +----------+----------+----------+----------+----------+ |
+------------------------------------------------------------+
```
Architecture Components:
- Valid Bit: Indicates if the cache line contains valid data (cleared on reset, set on load).
- Tag: The upper portion of the main memory address. Stored to identify which specific memory block is currently residing in this cache line.
- Data Block (Cache Line): The actual chunk of main memory data (typically 16, 32, or 64 bytes).
- Dirty Bit: Used in Write-Back caches. Indicates whether the data in the cache has been modified by the CPU and is not yet written back to main memory.
- LRU/Replacement Bits: Used to decide which line to evict when the cache is full.
