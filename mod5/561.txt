561. Show (({Z}, *)) with (x*y = x + y + 1) is abelian
- Closure: For integers (x,y), (x+y+1 Ɛ {Z}).
- Associativity:
  [  (x*y)*z = (x+y+1)+z+1 = x+y+z+2,]
  and
  [  x*(y*z) = x+(y+z+1)+1 = x+y+z+2.]
  So equal.
- Identity: Find (e) such that (x*e = x). We need (x+e+1 = x → e = -1).
- Inverse: For (x), find (x') such that (x*x' = -1). We need (x+x'+1 = -1 → x' = -x - 2).
- Commutative: (x*y = x+y+1 = y+x+1 = y*x).
Thus (({Z}, *)) is an abelian group.
