567. Show ((A, ▪)) is an abelian group
Given:
[A = {a Ɛ {Q} | a ╪ -1},\qquad a ▪ b = a + b + ab.]
- Closure: If (a,b ╪ -1), then
  [  a ▪ b = a + b + ab = (1+a)(1+b) - 1.]
  Since (a ╪ -1) and (b ╪ -1), we have ((1+a)(1+b) ╪ 0). Therefore (a ▪ b ╪ -1), so (a ▪ b Ɛ A).
- Associativity:
  [  (a ▪ b) ▪ c = (a+b+ab) + c + (a+b+ab)c]
  [  = a+b+c+ab+ac+bc+abc.]
  Similarly,
  [  a ▪ (b ▪ c) = a + (b+c+bc) + a(b+c+bc)]
  [  = a+b+c+bc+ab+ac+abc.]
  Both are equal, so (▪) is associative.
- Identity: Find (e) such that (a ▪ e = a):
  [  a + e + ae = a → e(1+a) = 0.]
  Since (a ╪ -1), we get (e = 0). Check: (0 Ɛ A) and (a ▪ 0 = a).
- Inverse: For (a Ɛ A), find (a') such that (a ▪ a' = 0):
  [  a + a' + aa' = 0 → a'(1+a) = -a → a' = \frac{-a}{1+a}.]
  Since (a ╪ -1), denominator is non‑zero. Also (a' ╪ -1) (if (a' = -1), then (-a/(1+a) = -1 → -a = -1-a → 0 = -1), impossible). Thus (a' Ɛ A).
- Commutativity: (a ▪ b = a+b+ab = b+a+ba = b ▪ a).
All group axioms are satisfied, and the operation is commutative. Hence ((A, ▪)) is an abelian group.
