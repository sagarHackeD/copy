567. Show ((A, \bullet)) is an abelian group

Given:
[A = {a Ɛ {Q} | a \neq -1},\qquad a \bullet b = a + b + ab.]

- Closure: If (a,b \neq -1), then
  [  a \bullet b = a + b + ab = (1+a)(1+b) - 1.
  \]
  Since (a \neq -1) and (b \neq -1), we have ((1+a)(1+b) \neq 0). Therefore (a \bullet b \neq -1), so (a \bullet b Ɛ A).

- Associativity:
  [  (a \bullet b) \bullet c = (a+b+ab) + c + (a+b+ab)c
  \]
  [  = a+b+c+ab+ac+bc+abc.
  \]
  Similarly,
  [  a \bullet (b \bullet c) = a + (b+c+bc) + a(b+c+bc)
  \]
  [  = a+b+c+bc+ab+ac+abc.
  \]
  Both are equal, so (\bullet) is associative.

- Identity: Find (e) such that (a \bullet e = a):
  [  a + e + ae = a → e(1+a) = 0.
  \]
  Since (a \neq -1), we get (e = 0). Check: (0 Ɛ A) and (a \bullet 0 = a).

- Inverse: For (a Ɛ A), find (a') such that (a \bullet a' = 0):
  [  a + a' + aa' = 0 → a'(1+a) = -a → a' = \frac{-a}{1+a}.
  \]
  Since (a \neq -1), denominator is non‑zero. Also (a' \neq -1) (if (a' = -1), then (-a/(1+a) = -1 → -a = -1-a → 0 = -1), impossible). Thus (a' Ɛ A).

- Commutativity: (a \bullet b = a+b+ab = b+a+ba = b \bullet a).

All group axioms are satisfied, and the operation is commutative. Hence ((A, \bullet)) is an abelian group.
