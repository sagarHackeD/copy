56. How is the Efficiency of Cache Measured?
Efficiency is measured by how effectively the cache reduces the average time it takes to access data.
Key Metrics:
- Hit Ratio (Hit Rate): `H = (Number of Hits) / (Total Access Attempts)`. Usually expressed as a percentage (e.g., 95%).
- Miss Ratio: `M = 1 - H` (e.g., 5%).
- Miss Penalty: The extra time (in clock cycles) required to fetch the data from main memory when a miss occurs. (e.g., 100 cycles).
- Hit Time: The time to access data on a cache hit (e.g., 1 cycle).
The Ultimate Efficiency Measure: Average Memory Access Time (AMAT)
The most important formula to measure cache performance is:
{AMAT} = {Hit Time} + ({Miss Rate} \times {Miss Penalty})
Example Calculation:
- CPU Clock: 1 ns per cycle.
- Hit Time = 1 cycle (1 ns).
- Miss Penalty = 50 cycles (50 ns).
- Miss Rate = 5% (0.05).
{AMAT} = 1 + (0.05 \times 50) = 1 + 2.5 = 3.5 { ns}
Conclusion: Even though the cache is extremely fast (1 ns), because of a 5% miss rate, the average time to access data is 3.5 ns. Reducing the miss rate to 1% would drop the AMAT to \(1 + (0.01 \times 50) = 1.5\) ns.
Profiling/Tools:
- Modern ARM cores have Performance Monitoring Units (PMUs) with counters specifically for `Cache Hit`, `Cache Miss`, and `Cache Refill` to help developers measure efficiency in real-time.
