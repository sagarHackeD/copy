
8. Prove that if t1(n) E O(g1(n)) and t2(n) E O(g2(n)) then t1(n) + t2(n) E O(max[g1(n), g2(n)]).
Proof: Since `t1(n) E O(g1(n))`, by definition, `t1(n) <= c1  g1(n)` for all `n => n1`.
Since `t2(n) E O(g2(n))`, by definition, `t2(n) <= c2  g2(n)` for all `n => n2`.
Now, let `n0 = max(n1, n2)` and `c = c1 + c2`. 
Adding the inequalities: `t1(n) + t2(n) <= c1g1(n) + c2g2(n)`.
Let `g_max(n) = max(g1(n), g2(n))`. 
Since `g1(n) <= g_max(n)` and `g2(n) <= g_max(n)`, we can write:
`t1(n) + t2(n) <= c1g_max(n) + c2g_max(n) = (c1 + c2)  g_max(n) = c  g_max(n)`.
Therefore, by definition, `t1(n) + t2(n) E O(max(g1, g2))`. Hence Proved.
