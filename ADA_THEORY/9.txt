
9. Write an algorithm for sequential search of an element using an array. Calculate best, avg and worst case efficiency.
Algorithm:
```
SEQUENTIAL(arr, n, key):
for i = 0 to n-1 do:
if arr[i] == key then:
return i        // Found at index i
end if
end for
return -1               // Not found
```
Efficiency (Basic Operation = Comparison `arr[i]==key`):
- Best Case: The key is the very first element (`arr[0]`). The loop executes only 1 time. Complexity = `\Omega(1)`.
- Worst Case: The key is the last element (`arr[n-1]`) or is not present. The loop executes `n` times. Complexity = `O(n)`.
- Average Case (Assumption: Key is present, and probability of key being at any index `i` is `1/n`):
- If the key is at `i=0`, comparisons = 1.
- If the key is at `i=1`, comparisons = 2.
- ...
- If the key is at `i=n-1`, comparisons = n.
- Total comparisons across all positions = `1 + 2 + ... + n = n(n+1)/2`.
- Average = `[n(n+1)/2] / n = (n+1)/2`.
- Dropping constants, Average Complexity = `\Theta(n)`.
