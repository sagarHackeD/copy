
27. What is backtracking? Apply backtracking to solve the Sum of Subset problem.
Definition: It is a systematic algorithmic technique where we build candidates for a solution incrementally. As soon as we determine that a partial candidate cannot possibly lead to a valid complete solution, we abandon it ("backtrack") to the previous step and try the next available alternative.
Problem Instance: Find subsets of `{3, 5, 6, 7}` that sum to `15`.
Backtracking Application (Sorted): `[3, 5, 6, 7]`. (State space pruning: If sum exceeds target, backtrack. If adding remaining all doesn't reach target, backtrack).
1. Start with {}.
2. Include 3: Sum=3. Include 5: Sum=8. Include 6: Sum=14. Include 7: Sum=21 > 15  Backtrack.
3. Remove 6, include 7: Sum=15. Solution Found: {3, 5, 7}.
4. Backtrack to include 6 without 5: Include 3, Include 6  Sum=9. Include 7  Sum=16 > 15. Backtrack.
5. Backtrack to start with 5: Include 5, Include 6, Include 7  Sum=18 > 15. Include 5, Include 6 (11)  remaining 7 makes 18, stop.
6. Start with 6, Include 7  Sum=13, cannot reach 15 (remaining none). Stop.
Final Solutions: `{3, 5, 7}`.
