1. Concept of Greedy Technique for Prim's Algorithm:
Prim's Algorithm is a greedy algorithm used to find the Minimum Spanning Tree (MST) of a weighted, connected, undirected graph. 

The Greedy Strategy: It grows a single tree from an arbitrary starting vertex. At each step, it looks at all edges that connect a vertex already in the tree to a vertex outside the tree. It greedily picks the edge with the minimum weight (cheapest edge) across this "cut" and adds that outside vertex to the tree. 
Why Greedy works here (Cut Property): For any partition (cut) of the graph's vertices, the minimum-weight edge crossing that cut is always safe (guaranteed to be part of some MST). Prim's algorithm repeatedly applies this logic, ensuring the final tree is globally optimal.
