
12. Explain Strassen's Multiplication and derive its time complexity.
Concept: Strassen's Matrix Multiplication is an optimization over the standard `O(n^3)` method. Standard multiplication of two 2x2 matrices requires 8 multiplications. Strassen proved we can do it in 7 multiplications using strategic additions and subtractions.
Strassen's 7 Multiplications (for 2x2 matrices `A` and `B`):
- `M1 = (A11 + A22)  (B11 + B22)`
- `M2 = (A21 + A22)  B11`
- `M3 = A11  (B12 - B22)`
- `M4 = A22  (B21 - B11)`
- `M5 = (A11 + A12)  B22`
- `M6 = (A21 - A11)  (B11 + B12)`
- `M7 = (A12 - A22)  (B21 + B22)`
- Result: `C11 = M1 + M4 - M5 + M7`, `C12 = M3 + M5`, etc.
Complexity Derivation:
- The algorithm divides the matrices into `n/2 x n/2` sub-matrices.
- It makes 7 recursive multiplications (`7  T(n/2)`) and the addition/subtraction step takes `O(n^2)` time.
- Recurrence: `T(n) = 7T(n/2) + O(n^2)`.
- Using Master Theorem: `a=7`, `b=2`, `f(n)=n^2`. 
- `n^(log_b a) = n^(log_2 7) ≈ n^2.807`.
- Since `f(n) = n^2` is strictly less than `n^2.807` (Case 1).
- Complexity = `O(n^(log_2 7))` ≈ `O(n^2.81)`.
