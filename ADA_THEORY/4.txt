
4. Find factorial of a number using Recursive Algorithm Analysis. Derive its efficiency.
Algorithm (Pseudo-code):
```
FACT(n):
if n == 0 or n == 1:  // Base case
return 1
else:                 // Recursive step
return n  FACT(n-1)
```
Detailed Analysis:
- Input size = `n`.
- Basic Operation = Multiplication (the `` operation inside the return statement).
- Recurrence Setup: 
- Base case: `T(1) = 1` (only a check is done, no multiplication).
- General case: `T(n) = T(n-1) + 1` (One recursive call to size `n-1`, plus 1 multiplication).
Derivation using Back Substitution:
- `T(n) = T(n-1) + 1`
- Substitute `T(n-1) = T(n-2) + 1` -> `T(n) = T(n-2) + 2`
- Substitute `T(n-2) = T(n-3) + 1` -> `T(n) = T(n-3) + 3`
- Continuing this pattern for `k` steps: `T(n) = T(n-k) + k`
- Let the base case hit `n-k = 1`, which means `k = n-1`.
- So, `T(n) = T(1) + (n-1) = 1 + n - 1 = n`.
Final Efficiency: Time Complexity = `O(n)`. Space Complexity = `O(n)` because the recursive call stack holds `n` active frames.
