
7. Suggest non-recursive algorithm for finding maximum element in a list of n-elements. Derive its efficiency.
Algorithm (Iterative):
```
MAXIMUM(arr, n):
max = arr[0]
for i = 1 to n-1 do:
if arr[i] > max then:
max = arr[i]
end if
end for
return max
```
Efficiency Derivation:
- Input size = `n`.
- Basic operation = Comparison (`arr[i] > max`).
- The loop runs exactly `n-1` times, regardless of the data arrangement.
- Therefore, total basic operations = `n - 1`.
- Dropping constants and lower-order terms: `T(n) = n - 1 = O(n)`.
- Result: Time Complexity = `O(n)` (Linear), Space Complexity = `O(1)`.
