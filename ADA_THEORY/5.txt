
5. Write Tower of Hanoi Algorithm using recursive algorithm analysis. Derive its efficiency.
Algorithm:
```
HANOI(n, source, dest, aux):
if n == 1:
Move disk 1 from source to dest
return
HANOI(n-1, source, aux, dest)   // Move top n-1 to auxiliary
Move disk n from source to dest   // Move largest
HANOI(n-1, aux, dest, source)    // Move n-1 to destination
```
Analysis: Basic operation is "Move disk".
Recurrence: 
- Base case: `T(1) = 1`.
- General case: `T(n) = 2  T(n-1) + 1` (Two recursive calls on size `n-1`, plus moving the largest disk).
Derivation:
- `T(n) = 2T(n-1) + 1`
- Expand: `T(n) = 2[2T(n-2) + 1] + 1 = 2^2  T(n-2) + 2 + 1`
- Expand fully: `T(n) = 2^3  T(n-3) + 2^2 + 2 + 1`
- Generalizing: `T(n) = 2^(n-1)  T(1) + 2^(n-2) + ... + 2^2 + 2 + 1`
- This is a geometric progression: `T(n) = 1 + 2 + 4 + ... + 2^(n-1) = 2^n - 1`.
Final Efficiency: Time = `O(2^n)` (Exponential). This is the classic limitation of the Tower of Hanoi.
