
20. What are Huffman Trees? Construct the Huffman Tree and Encode DAD-CBE.
Let's define data: Characters with frequencies: `A:5`, `B:2`, `C:4`, `D:7`, `E:1`. Text to encode: `"DAD-CBE"`.
Construction:
1. Sort by freq: `E(1)`, `B(2)`, `C(4)`, `A(5)`, `D(7)`.
2. Merge E(1) and B(2)  Node N1 = 3.
3. Merge N1(3) and C(4)  Node N2 = 7.
4. Merge A(5) and N2(7)  Node N3 = 12.
5. Merge N3(12) and D(7)  Node N4 = 19. (Tree is built).
Assign Codes (Left=0, Right=1):
- D: `0`
- A: `10`
- C: `110`
- B: `1110`
- E: `1111`
Encode "DAD-CBE":
- D = `0`
- A = `10`
- D = `0`
- - (ignore hyphen or encode as space)
- C = `110`
- B = `1110`
- E = `1111`
Final Code: `0 10 0 110 1110 1111`  `010011011101111`.
