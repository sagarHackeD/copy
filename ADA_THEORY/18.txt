
18. Construct a bottom up heap for the given list and obtain its time complexity.
Let's take Example List: `[5, 3, 8, 1, 9, 2]` (Indices: 0 to 5).
Bottom-Up Construction:
1. Start from the last internal node. Last internal node index = `floor(n/2) - 1 = floor(6/2) - 1 = 3 - 1 = 2`. (Element `8` at index 2).
2. Heapify index 2 (`8`): Left child is `2` (index 5), right child `-` (none). Max is `8`. No swap.
3. Heapify index 1 (`3`): Left child `1` (idx 3), Right child `9` (idx 4). Max is `9`. Swap `3` and `9`. Array becomes `[5, 9, 8, 1, 3, 2]`.
4. Heapify index 0 (`5`): Left child `9` (idx 1), Right child `8` (idx 2). Max is `9`. Swap `5` and `9`. Array: `[9, 5, 8, 1, 3, 2]`.
5. Since we swapped at index 1 (`5`), we heapify index 1: Left child `1` (idx 3), Right child `3` (idx 4). Max is `5` (parent). No swap.
Final Max-Heap: `[9, 5, 8, 1, 3, 2]`.
Time Complexity: While a single heapify operation takes `O(log n)`, the sum of heights of all internal nodes in a complete binary tree is `O(n)`. Therefore, the total complexity of bottom-up heap construction is `O(n)` (Linear time).
