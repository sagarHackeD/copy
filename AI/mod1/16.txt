16. Explain the relationship between an agent and its environment
with an example.
An agent observes its environment, receives information called a percept, and selects an action. The action
changes the environment, and the agent receives new percepts.
Example – Automatic vacuum cleaner:
* If the vacuum detects dirt, it sucks up the dirt.
* If the current square is clean, it moves to the other square.
* It repeats this process based on the information it receives.
Thus, the agent and environment interact continuously through perception and action.
