11. Describe the operation of a connectionless packet-switched network with a neat diagram.

A connectionless packet-switched network is a network in which data is divided into packets, and each packet travels independently without establishing a connection beforehand. It is also called a datagram network.

Operation:
1. The sender divides data into packets.
2. Each packet contains source and destination addresses.
3. Routers independently select a route for each packet.
4. Packets may travel through different routes.
5. The destination reassembles the packets if required.

Diagram:
          Source
             |
        +----+----+
        |         |
      Router 1  Router 2
        |         |
        +----+----+
             |
        Destination

adv: Efficient resource utilization and flexible routing.
Dadv: Variable delay, packet loss, and out-of-order delivery.
Ex: Internet Protocol (IP).
