16. Functional Dependency and Minimal Cover
Algorithm for Minimal Cover
1. Ensure single attribute on RHS.
2. Remove extraneous attributes from LHS.
3. Remove redundant dependencies.
Given:
E = { B->A, D->A, AB->D }
Step 1
Already single RHS.
Step 2
Check AB->D
Since:
B->A
AB->D
A is extraneous in AB->D.
Therefore:
B->D
Step 3
Now set becomes:
{ B->A, B->D, D->A }
Since:
B->D
D->A
By transitivity:
B->A
is redundant.
Minimal Cover
M = { B->D, D->A }
