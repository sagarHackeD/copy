3. Functional Dependency and Inference Rules
Functional Dependency
A functional dependency (FD) X -> Y means that if two tuples have the same value for X, they must have the same value for Y.
Example:
StudentID -> StudentName
Armstrong's Inference Rules
1. Reflexivity
If Y ⊆ X then
X -> Y
Proof: Since Y is part of X, same X implies same Y.
2. Augmentation
If
X -> Y
Then
XZ -> YZ
Proof: Adding same attributes on both sides preserves dependency.
3. Transitivity
If
X -> Y
Y -> Z
Then
X -> Z
Proof: X determines Y and Y determines Z, therefore X determines Z.
