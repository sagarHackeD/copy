2. Explain One-One Function, Onto Function and Bijective Function

One-One Function (Injective)
A function is one-one if different elements of the domain have different images.
f(a)=f(b)\Rightarrow a=b
Example
f(x)=2x
Since distinct inputs give distinct outputs, the function is one-one.

Onto Function (Surjective)
A function is onto if every element of the codomain has at least one pre-image in the domain.
For every y \in B
there exists x \in A
such that f(x)=y
Example
f(x)=x^3
from R to R is onto because every real number has a cube root.

Bijective Function
A function that is both one-one and onto is called bijective.
Example
f(x)=x+5
from R to R is bijective.
