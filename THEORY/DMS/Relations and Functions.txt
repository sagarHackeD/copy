1. Explain Relations and Functions

Relation
A relation from a set A to a set B is a subset of the Cartesian product A × B.
If R is a relation from A to B, then
R \subseteq A \times B
A relation consists of ordered pairs (a,b), where a belongs to A and b belongs to B.
Example
Let
A=\{1,2,3\} B=\{a,b\}
Then
R=\{(1,a),(2,b),(3,a)\}
is a relation from A to B.

Function
A function is a special type of relation in which every element of the domain is associated with exactly one element of the codomain.
f:A \rightarrow B
For every a \in A
there exists exactly one b \in B
such that f(a)=b
Example
f(x)=2x+1
Then
f(1)=3,\quad f(2)=5,\quad f(3)=7
