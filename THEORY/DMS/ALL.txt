1. Explain Relations and Functions

Relation
A relation from a set A to a set B is a subset of the Cartesian product A × B.
If R is a relation from A to B, then
R \subseteq A \times B
A relation consists of ordered pairs (a,b), where a belongs to A and b belongs to B.
Example
Let
A=\{1,2,3\} B=\{a,b\}
Then
R=\{(1,a),(2,b),(3,a)\}
is a relation from A to B.

Function
A function is a special type of relation in which every element of the domain is associated with exactly one element of the codomain.
f:A \rightarrow B
For every a \in A
there exists exactly one b \in B
such that f(a)=b
Example
f(x)=2x+1
Then
f(1)=3,\quad f(2)=5,\quad f(3)=7



2. Explain One-One Function, Onto Function and Bijective Function

One-One Function (Injective)
A function is one-one if different elements of the domain have different images.
f(a)=f(b)\Rightarrow a=b
Example
f(x)=2x
Since distinct inputs give distinct outputs, the function is one-one.

Onto Function (Surjective)
A function is onto if every element of the codomain has at least one pre-image in the domain.
For every y \in B
there exists x \in A
such that f(x)=y
Example
f(x)=x^3
from R to R is onto because every real number has a cube root.

Bijective Function
A function that is both one-one and onto is called bijective.
Example
f(x)=x+5
from R to R is bijective.



3. Definitions

(a) Group
A non-empty set G together with a binary operation * is called a group if:
Closure
Associativity
Identity element exists
Inverse exists for every element
Mathematically,
(G,*)
is a group.

(b) Order of a Group
The number of elements in a group is called its order.
Example:
G=\{0,1,2\}
has order 3.

(c) Abelian Group
A group is Abelian if the operation is commutative.
a*b=b*a
for all
a,b \in G

(d) Finite and Infinite Group
Finite Group
A group having finite number of elements.
Example:
Z_5=\{0,1,2,3,4\}
Infinite Group
A group having infinitely many elements.
Example:
(Z,+)

11. State and Prove Lagrange's Theorem
Statement
If G is a finite group and H is a subgroup of G, then
|H|
divides
|G|
and
|G|=[G:H]|H|
where
[G:H]
is the index of H in G.
Proof
The left cosets of H in G partition G.
Every left coset contains exactly
|H|
elements.
Suppose there are
k
distinct left cosets.
Then the elements of G are distributed among these k disjoint cosets.
Therefore
|G|=k|H|
Since k is an integer,
|H|
divides
|G|
```.
Hence proved.

14. Show that (G,*) is an Abelian Group

and
a*b=\frac{ab}{2}

Since a and b are non-zero reals,
\frac{ab}{2}
is also a non-zero real.

Associativity
(a*b)*c
=\frac{ab}{2}*c
=\frac{abc}{4}

a*(b*c)
=a*\frac{bc}{2}
=\frac{abc}{4}
Therefore associative.
Identity
Let e be identity.

\frac{ae}{2}=a
e=2

2

For a inverse of a:

\frac{4}{a}

16. Define a Group and Show Fourth Roots of Unity Form an Abelian Group
The fourth roots of unity are
\{1,-1,i,-i\}
under multiplication.
Closure
Product of any two fourth roots is again a fourth root.
Associativity
Inherited from complex multiplication.
Identity
1
is the identity.
Inverses
1^{-1}=1
(-1)^{-1}=-1
i^{-1}=-i
(-i)^{-1}=i
Commutativity
Complex multiplication is commutative.
Hence
\{1,-1,i,-i\}
forms an Abelian group.
