1) Explain ARM Processor Exceptions and Modes with Neat Diagram
ARM Processor Exceptions

An exception is an event that interrupts the normal execution flow of a program and causes the processor to execute a special routine called an Exception Handler.

ARM processors support several exceptions to handle errors, interrupts, and system services.

Types of ARM Exceptions
Exception	Vector Address	Description
Reset	0x00000000	Occurs when the processor is powered on or reset.
Undefined Instruction	0x00000004	Generated when an invalid instruction is executed.
Software Interrupt (SWI/SVC)	0x00000008	Used by applications to request OS services.
Prefetch Abort	0x0000000C	Occurs when instruction fetch fails.
Data Abort	0x00000010	Occurs when data access fails.
IRQ	0x00000018	Normal interrupt request.
FIQ	0x0000001C	Fast interrupt request with higher priority.
ARM Processor Modes

ARM supports different operating modes.

Mode	Purpose
User	Normal application execution
System	Privileged version of User mode
Supervisor (SVC)	Entered after reset or SWI
IRQ	Handles normal interrupts
FIQ	Handles fast interrupts
Abort	Handles memory access faults
Undefined	Handles undefined instructions

Each exception has a dedicated vector address.
Processor automatically saves state information.
Processor switches to an appropriate exception mode.
Execution resumes after exception servicing.
2) Explain Exception Priorities and Link Register (LR) Offset
Exception Priorities

When multiple exceptions occur simultaneously, ARM processes them according to priority.

Priority Order
Priority	Exception
Highest	Reset
2	Data Abort
3	FIQ
4	IRQ
5	Prefetch Abort
6	Undefined Instruction
Lowest	SWI/SVC
Link Register (LR)

During exception handling, ARM saves the return address in the Link Register (LR) of the exception mode.

Purpose
Stores the address to return after exception processing.
Allows execution to continue where it stopped.
LR Offset Values
Exception	LR Contains
Undefined	PC + 4
SWI	PC + 4
Prefetch Abort	PC + 4
Data Abort	PC + 8
IRQ	PC + 4
FIQ	PC + 4
Return Instructions
SUBS PC, LR, #4

or

SUBS PC, LR, #8

depending on the exception type.

5) Briefly Explain What Happens When an IRQ/FIQ Exception Is Raised
IRQ Handling

When IRQ occurs:

Current instruction completes.
CPSR copied to SPSR_irq.
Return address stored in LR_irq.
Processor enters IRQ mode.
IRQ disabled.
PC loaded with IRQ vector address.
ISR executes.
Context restored.
Return to interrupted program.

6) Explain Design and Implementation of Interrupt Stacks in ARM-Based Systems
Interrupt Stack

An interrupt stack stores processor state during interrupt processing.

Need
Prevent data corruption.
Allow nested interrupts.
Separate user and interrupt execution contexts.
Design

Each mode has its own stack.

User Stack
IRQ Stack
FIQ Stack
SVC Stack
Abort Stack
Undefined Stack
Initialization
LDR SP, =IRQ_STACK_TOP

for IRQ mode.

Similarly for other modes.

Interrupt Stack Operation
Step 1

Interrupt occurs.

Step 2

CPU switches mode.

Step 3

Registers pushed onto stack.

STMFD SP!, {R0-R12, LR}
Step 4

ISR executes.

Step 5

Registers restored.

LDMFD SP!, {R0-R12, LR}
Step 6

Return from interrupt.

Advantages
Reliable context switching.
Supports nested interrupts.
Improves system stability.
