4) Explain Assigning Interrupts and Interrupt Latency
Assigning Interrupts

Interrupt assignment maps hardware devices to interrupt sources.

Steps
Interrupt generated by device.
Interrupt controller receives request.
Priority assigned.
CPU acknowledges interrupt.
ISR (Interrupt Service Routine) executes.

Interrupt Latency

Interrupt latency is the time between interrupt generation and execution of the first ISR instruction.

Factors Affecting Latency
Current CPU activity
Interrupt masking
Pipeline flushing
Context saving
Memory speed
Interrupt controller delay
Formula
Interrupt Latency =
Detection Time +
Pipeline Delay +
Context Save Time +
ISR Start Time
