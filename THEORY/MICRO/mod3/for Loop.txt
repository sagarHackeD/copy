9) How Compiler Handles a for Loop with Variable Number of Iterations (n) and Loop Unrolling with Example
Variable Iteration Loop
Example
for(int i=0;i<n;i++)
{
    sum += a[i];
}

Compiler cannot determine the value of n during compilation.

Generated Steps
Initialize i
Compare i<n
Execute Loop Body
Increment i
Repeat
Loop Overhead

Each iteration performs:

Comparison
Branch
Increment

These consume extra cycles.

Loop Unrolling

Loop unrolling reduces loop overhead by executing multiple iterations in one loop pass.

Original Loop
for(int i=0;i<8;i++)
{
    sum += a[i];
}
Unrolled Version
sum += a[0];
sum += a[1];
sum += a[2];
sum += a[3];
sum += a[4];
sum += a[5];
sum += a[6];
sum += a[7];
Partial Unrolling
for(int i=0;i<8;i+=4)
{
    sum += a[i];
    sum += a[i+1];
    sum += a[i+2];
    sum += a[i+3];
}
Advantages
Fewer branch instructions
Reduced loop overhead
Better instruction scheduling
Higher execution speed
Disadvantages
Larger code size
Increased memory usage
