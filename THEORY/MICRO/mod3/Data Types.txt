5) Explain Different Basic Data Types in C with Examples
Basic Data Types
1. char

Stores characters.

char grade='A';

Size: 1 byte

2. int

Stores integers.

int age=20;

Typically 4 bytes.

3. float

Stores single-precision floating-point values.

float pi=3.14;

Size: 4 bytes.

4. double

Stores double-precision values.

double value=123.456789;

Size: 8 bytes.

5. void

Represents absence of value.

void display();
| Data Type | Example  | Typical Size |
| --------- | -------- | ------------ |
| char      | 'A'      | 1 byte       |
| int       | 100      | 4 bytes      |
| float     | 3.14     | 4 bytes      |
| double    | 3.141592 | 8 bytes      |
| void      | None     | No storage   |
