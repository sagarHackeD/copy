1) Explain Code Optimization, Profiling and Cycle Counting
Code Optimization

Code optimization is the process of improving a program so that it executes faster, consumes less memory, or uses fewer system resources without changing its functionality.

Objectives
Reduce execution time
Reduce memory usage
Lower power consumption
Improve code efficiency
Types of Optimization
1. Compile-Time Optimization

Performed by the compiler.

Examples:

Constant folding
Dead code elimination
Function inlining
Loop unrolling
int x = 10 * 20;

Compiler replaces it with:

int x = 200;
2. Manual Optimization

Programmer modifies code.

Example:

for(int i=0;i<1000;i++)
{
    sum += array[i];
}

Using pointers can reduce indexing overhead.

Profiling

Profiling is the process of measuring where a program spends its execution time.

Purpose
Find bottlenecks
Improve performance
Analyze memory usage
Profiling Information
Function execution time
Number of function calls
Memory consumption
CPU utilization
Profiling Process
Program
   |
Execute
   |
Collect Runtime Data
   |
Analyze Hot Spots
   |
Optimize Code
Cycle Counting

Cycle counting measures the number of CPU clock cycles required to execute code.

Formula
Execution Time =
Clock Cycles / CPU Frequency

Example:

If CPU frequency = 100 MHz

Cycles = 500

Execution Time = 500 / 100,000,000
               = 5 μs
Importance
Real-time systems
Embedded applications
Performance tuning

3) Discuss How Registers Are Allocated to Optimize the Program
Register Allocation

Register allocation is the process of assigning frequently used variables to CPU registers instead of memory locations.

Registers provide the fastest access.

Why Register Allocation?

Memory access:

RAM Access > Register Access

Registers reduce execution time.

Example

Without register allocation:

sum = a + b;

Compiler repeatedly accesses memory.

With register allocation:

LDR r0,[a]
LDR r1,[b]
ADD r2,r0,r1

Variables remain in registers.

Benefits
Faster execution
Reduced memory accesses
Lower power consumption
Better CPU utilization

8) Explain the Concept of Pointer Aliasing with Example
Pointer Aliasing

Pointer aliasing occurs when two or more pointers refer to the same memory location.

Example
int x = 10;

int *p = &x;
int *q = &x;

*q = 20;

Both pointers refer to the same variable.

Memory Representation
      x = 20
      |
   --------
   |      |
   p      q
Problem

Compiler optimization becomes difficult because changing through one pointer affects the other.

Example
void update(int *a, int *b)
{
    *a = 5;
    *b = 10;
}

If a and b point to the same location:

update(&x,&x);

Final value becomes:

10
Solution

Use restrict keyword.

void update(int *restrict a,
            int *restrict b)
{
}

This tells the compiler the pointers do not alias.

9) How Compiler Handles a for Loop with Variable Number of Iterations (n) and Loop Unrolling with Example
Variable Iteration Loop
Example
for(int i=0;i<n;i++)
{
    sum += a[i];
}

Compiler cannot determine the value of n during compilation.

Generated Steps
Initialize i
Compare i<n
Execute Loop Body
Increment i
Repeat
Loop Overhead

Each iteration performs:

Comparison
Branch
Increment

These consume extra cycles.

Loop Unrolling

Loop unrolling reduces loop overhead by executing multiple iterations in one loop pass.

Original Loop
for(int i=0;i<8;i++)
{
    sum += a[i];
}
Unrolled Version
sum += a[0];
sum += a[1];
sum += a[2];
sum += a[3];
sum += a[4];
sum += a[5];
sum += a[6];
sum += a[7];
Partial Unrolling
for(int i=0;i<8;i+=4)
{
    sum += a[i];
    sum += a[i+1];
    sum += a[i+2];
    sum += a[i+3];
}
Advantages
Fewer branch instructions
Reduced loop overhead
Better instruction scheduling
Higher execution speed
Disadvantages
Larger code size
Increased memory usage
