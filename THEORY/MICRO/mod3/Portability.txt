7) Discuss Common Portability Issues Faced When Porting C Programs
Portability

Portability means a program can run on different platforms with little or no modification.

Common Issues
1. Data Type Size Differences
int x;

Size may differ between systems.

2. Endianness
Little Endian

Lowest byte stored first.

Big Endian

Highest byte stored first.

3. Compiler Differences

Different compilers may support different extensions.

4. Pointer Size

32-bit system:

Pointer = 4 bytes

64-bit system:

Pointer = 8 bytes
5. Operating System Dependencies

Example:

#include <windows.h>

Not portable to Linux.

Solutions
Use standard C libraries.
Avoid compiler-specific code.
Use fixed-width types.
#include <stdint.h>

uint32_t value;
