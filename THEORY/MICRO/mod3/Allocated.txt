Register Allocation

Register allocation is the process of assigning frequently used variables to CPU registers instead of memory locations.

Registers provide the fastest access.

Why Register Allocation?

Memory access:

RAM Access > Register Access

Registers reduce execution time.

Example

Without register allocation:

sum = a + b;

Compiler repeatedly accesses memory.

With register allocation:

LDR r0,[a]
LDR r1,[b]
ADD r2,r0,r1

Variables remain in registers.

Benefits
Faster execution
Reduced memory accesses
Lower power consumption
Better CPU utilization
