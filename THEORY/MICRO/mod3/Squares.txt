2) Write a C Program That Prints Squares of Integers from 0 to 9 Using Functions and Explain Conversion to Assembly Function
C Program
#include <stdio.h>

int square(int n)
{
    return n * n;
}

int main()
{
    int i;

    for(i=0;i<=9;i++)
    {
        printf("%d = %d\n", i, square(i));
    }

    return 0;
}
Output
0 = 0
1 = 1
2 = 4
3 = 9
4 = 16
5 = 25
6 = 36
7 = 49
8 = 64
9 = 81
Converting Function to ARM Assembly
C Function
int square(int n)
{
    return n*n;
}
ARM Assembly Function
square
    MUL r0, r0, r0
    BX  lr
Explanation
Input parameter passed in R0.
MUL computes R0 × R0.
Result stored in R0.
BX LR returns to caller.
