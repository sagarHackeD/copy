8) Explain the Concept of Pointer Aliasing with Example
Pointer Aliasing

Pointer aliasing occurs when two or more pointers refer to the same memory location.

Example
int x = 10;

int *p = &x;
int *q = &x;

*q = 20;

Both pointers refer to the same variable.

Memory Representation
      x = 20
      |
   --------
   |      |
   p      q
Problem

Compiler optimization becomes difficult because changing through one pointer affects the other.

Example
void update(int *a, int *b)
{
    *a = 5;
    *b = 10;
}

If a and b point to the same location:

update(&x,&x);

Final value becomes:

10
Solution

Use restrict keyword.

void update(int *restrict a,
            int *restrict b)
{
}

This tells the compiler the pointers do not alias.
