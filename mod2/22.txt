22. Unary Relational Operators
In relational algebra, unary operators operate on a single relation. The two most important are:
- SELECT (6) - Selects tuples (rows) that satisfy a given condition.
- PROJECT (\pi) - Selects attributes (columns), returning only the specified columns and eliminating duplicate rows.
Another unary operator is RENAME (p) , which changes the name of a relation or its attributes.
# Examples
Consider a relation `EMPLOYEE`:
emp_id name dept salary
----------------------
101   Alice IT   60000 
102   Bob  HR   45000 
103   Carol IT   70000 
104   Dave Sales50000 
- SELECT example:  
  `6_dept='IT'_(EMPLOYEE)` returns rows where department is IT:
emp_id name dept salary
---------------------
101   Alice IT  60000 
103   Carol IT  70000 
- PROJECT example:  
  `\pi_name,dept(EMPLOYEE)` returns only name and dept columns, with duplicates removed:
name dept 
----------
Alice IT   
Bob   HR   
Carol IT   
Dave  Sales
- RENAME example:  
  `p(EMP, employee_id, full_name, department, sal)(EMPLOYEE)` changes the relation name to `EMP` and attribute names accordingly.
