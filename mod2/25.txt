25. Relational Algebra Operations for Set Theory
Relational algebra includes standard set-theoretic operations provided that the relations are type-compatible (union-compatible): they must have the same degree (number of attributes) and corresponding domains must be compatible.
Operations:
UNION ( u )  
Returns all tuples that appear in either relation. Duplicates are eliminated (relations are sets).  
Example: 
R = { (1, A), (2, B) }  
S = { (2, B), (3, C) }  
R u S = { (1, A), (2, B), (3, C) }
INTERSECTION ( n )  
Returns tuples present in both relations.  
Example:
R n S = { (2, B) }
DIFFERENCE ( - )  
Returns tuples that are in the first relation but not in the second.  
Example:
R - S = { (1, A) }  
S - R = { (3, C) }
CARTESIAN PRODUCT ( x )  
Does not require type compatibility. Produces a relation whose schema is the concatenation of the two schemas, and every tuple from the first is paired with every tuple from the second.  
Example:
R(A,B) with tuples {(a1,b1), (a2,b2)} and S(C) with {(c1), (c2)}.  
R x S = { (a1,b1,c1), (a1,b1,c2), (a2,b2,c1), (a2,b2,c2) }.
